# Roberts Macros artwork

`RobertsMacros.png` contains the Roberts Macros brand artwork displayed in the setup window.

Finder menus use native monochrome SF Symbols: `arrow.left.arrow.right` for Convert and `doc.on.doc` for PDF. Finder supplies the foreground colour for normal, dark and selected menu states.

Build 3 replaces the earlier bitmap-to-template renderer, which was reported to show a black rectangle. Both new images retain transparent backgrounds through secure image archiving. Actual Finder screenshot inspection remains unavailable through the development UI tool; user visual confirmation is tracked separately from the image checks.
